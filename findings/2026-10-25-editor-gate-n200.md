# Editor gate at the pre-registered n=200 (2026-10-25)

## Question

Does the mixed-mask fine-tune lift one-block infill above the pre-registered
floor of `on-thesis >= 0.20` on the ordinary `test` split?

## Measurement

`scripts/check_backbone.py`, n=200, steps=8, seed=0, reasoner-free unless
stated. Wilson 95% intervals. `test` and `unseen` are separate runs and are
never pooled. Artifacts: `results/gate_*.json`.

| Condition | Split | on-thesis | 95% CI | Floor |
|---|---|---|---|---|
| LoRA-only 5k (before) | test | 29/200 = 0.145 | [0.103, 0.200] | fail |
| LoRA-only 5k (before) | unseen | 28/200 = 0.140 | [0.099, 0.195] | fail |
| LoRA-only mixed-mask | test | 49/200 = 0.245 | [0.191, 0.309] | pass (CI touches floor) |
| LoRA-only mixed-mask | unseen | 50/200 = 0.250 | [0.195, 0.314] | pass (CI touches floor) |
| CGR 5k (before) | test | 43/200 = 0.215 | [0.164, 0.277] | pass (CI touches floor) |
| CGR 5k (before) | unseen | 39/200 = 0.195 | [0.146, 0.255] | fail |
| **CGR mixed-mask** | **test** | **76/200 = 0.380** | **[0.316, 0.449]** | **pass** |
| CGR mixed-mask | unseen | 38/200 = 0.190 | [0.142, 0.250] | fail |
| CGR mixed-mask + reasoner | test | 76/200 = 0.380 | [0.316, 0.449] | pass (identical) |
| CGR mixed-mask + reasoner | unseen | 38/200 = 0.190 | [0.142, 0.250] | fail |

## Interpretation

1. The pre-registered gate is cleared: the only condition whose whole interval
   sits above 0.20 is the CGR mixed-mask fine-tune on `test`.

2. **Correction to an earlier claim.** The pre-fine-tune CGR checkpoint was
   reported at 0.175 (7/40) and called a failure. At n=200 the same untouched
   weights measure 0.215 [0.164, 0.277]. The n=40 interval was roughly
   +/-0.12 wide, so 0.175 could not be distinguished from 0.25. The "repair
   floor failure" was partly a small-sample artifact, and the earlier
   write-up overstated it. The honest statement is that the fine-tune moved a
   borderline model to a clearly-passing one.

3. Both arms improved under the same objective: LoRA-only +0.100
   (0.145 -> 0.245), CGR +0.165 (0.215 -> 0.380). Mixed masking is not
   CGR-specific.

4. `parseable == on_thesis` in every reasoner-free run, exactly. The gate is
   effectively a parse rate; the scorer does not independently confirm block
   content beyond the thesis id. This is a property of the scorer, present
   before fine-tuning (7 == 7) as well.

5. `unseen` disagrees with `test` for CGR, and the disagreement is a crossover:
   the fine-tuned CGR is 0.380 on `test` but **0.190 on `unseen`**, below the
   floor, while the LoRA-only control is 0.245 on `test` and 0.250 on `unseen`.
   The CGR advantage therefore does not transfer to held-out theses; the
   LoRA-only arm is the more stable of the two across splits. Do not pool the
   splits and do not substitute one for the other.

## What this does not support

- No claim that the CGR *architecture* helped. See
  [inert-side-channel](2026-10-25-inert-side-channel.md): the conditioning path
  was dead in this checkpoint, so the comparison is auxiliary supervision vs
  denoising alone.
- No claim about unseen-thesis repair.
- No claim about compute-matched superiority: CGR trained 9,898 s with
  8,149,661 trainable parameters; LoRA-only 4,141 s with 442,368.
- The `test` split has now been used to select the checkpoint, so it is no
  longer a clean test set for any further tuning. Confirm future changes on
  `unseen`.
